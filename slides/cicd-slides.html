The safety gate

What if a test fails?

Good code
Test ✓
→
Build ✓
→
Deploy ✓
→
New version live
Bad code
Test ✗
■
Buildskipped
→
Deployskipped
→
Old version stays

The pipeline stops. Bad code never reaches users.

5
CD has two meanings

Delivery vs Deployment

Continuous Delivery

The code is always ready to go live.

A person clicks "Approve" to release it.

CI ✓ → 👤 Approve → Live

Continuous Deployment

The code goes live automatically.

No human step. Tests are the only gate.

CI ✓ → Live

Healthcare (like HealthTechGov) often uses Delivery: a person approves first.
